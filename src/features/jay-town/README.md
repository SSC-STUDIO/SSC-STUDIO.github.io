# 樱花小镇

独立 Astro 页面：`/jay-town/`。在 `site/` 中运行 `npm run dev` 后访问该路径。

- WASD / 方向键行走，Shift 加速，拖动场景转头，滚轮前进或后退。
- 数字 1–5 或底部站名切换樱花街口、唱片小巷、晴天广场、花海车站、七里香河堤。
- 手机上使用方向按钮移动，拖动场景转头。
- 点击唱片按钮打开 20 首歌的歌单，支持搜索、场景筛选和本机收藏。
- 点击歌曲打开 Bilibili 的分集播放器；收起保留播放器，关闭会卸载并停止。歌曲来源见 `SOURCES.md`。

`scene.ts` 管理镜头、移动碰撞、昼夜和资源生命周期；`world.ts` 创建街道与樱花布局，`canopy.ts` 绘制细花簇；`details.ts`、`storefronts.ts`、`textures.ts` 提供细节及本地绘制材质。尊重系统减少动态效果设置；隐藏页面时停止渲染，静态阴影在进入新的街道区段时更新。WebGL 不可用时显示从本场景渲染的静态画面，仍可查看歌单；禁用脚本时可打开歌曲原站链接。

Pages 工作流构建 Astro 后，仅将 `dist/jay-town/` 与所需的 `dist/_astro/` 资源加入现有静态发布目录。网站其余页面保持当前的独立部署流程。
