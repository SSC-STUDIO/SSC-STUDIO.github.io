# Chen Runsen — personal site

This repository publishes a website. **It does not contain its source.**

| | |
|---|---|
| **Published site** | https://ssc-studio.github.io/ |
| **Live branch** | [`gh-pages`](../../tree/gh-pages) — built output only |
| **Source** | private, at `SSC-STUDIO/chenrunsen-website` |

## Why it is split this way

Two things pushed the source out of here.

**Weight.** The build carries media assets — album artwork and video — that add up
to tens of megabytes, plus local masters several times larger again. Keeping
those in a public repository means publishing them, permanently, in a history
that survives deletion, every clone and every fork.

**Provenance.** Some of the material is personal, and some of it was downloaded
from elsewhere and is not ours to redistribute. A public repository cannot tell
those apart from the things that are fine: once a file is committed here it is
public, full stop. A private source repository and a public output branch can.

## What is in `gh-pages`

Everything under it is generated by `astro build` and then copied in — the
pages, the `_astro` bundle, `jay-town/`, `mini-love/`, and the redirect that
sits at the root. There is no hand-written source there and no build
configuration; editing it by hand would simply be overwritten by the next
publish.
